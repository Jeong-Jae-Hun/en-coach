# en-coach

Claude Code에서 한글로 프롬프트를 쓰면, 영어로 어떻게 쓰면 좋을지 입력창 위에 추천해 주는 mod입니다.
영어로 프롬프트를 쓰는 연습을 하려고 만들었습니다.

- 한글로 치다가 멈추면 입력창 위에 `번역` 버튼과 3초 카운트다운이 뜹니다. 0이 되면 자동으로, 버튼을 누르면 바로 번역합니다.
- Haiku가 영어 문장 2개와 한글 팁을 만들어 입력창 위에 띄웁니다. 한글 프롬프트를 그대로 보내도 그 문장의 추천이 뜹니다.
- `넣기`를 누르거나 Option(Alt)+1, 2를 누르면 그 문장으로 입력창을 바꿉니다. Option+3은 카운트다운을 기다리지 않고 바로 번역합니다. 입력창이 비어 있으면 숫자만 눌러도 됩니다. 영어로 보내면 띠가 사라집니다.
- `기록`을 누르면 오른쪽 패널에 지난 추천과 이 세션의 Haiku 토큰 사용량이 나옵니다.
- `/en`으로 켜고 끕니다.
- `/en-term 씨미=ci.me`로 고유명사·은어를 등록하면 번역할 때 늘 그 표기를 씁니다. `/en-term`은 목록, `/en-term -씨미`는 삭제입니다. 용어집은 JSON 파일(`~/.claude/en-coach-glossary.json`, 환경 변수 `EN_COACH_GLOSSARY`로 변경)에 저장돼 세션이 바뀌어도 남고, dotfiles 같은 git 저장소에 두면 머신 간에도 동기화됩니다.
- 번역 중 모르는 고유명사·은어가 나오면 띠에 입력칸이 뜹니다. 영어 표기를 적고 Enter를 누르면 용어집에 추가하고 다시 번역합니다.

추천 한 번마다 Haiku를 한 번 호출합니다.

## 설치

터미널에서 연 Claude Code 세션의 프롬프트에 입력합니다.

```
/plugin install en-coach --marketplace Jeong-Jae-Hun/en-coach
```

`y`로 마켓플레이스 추가를 승인하고 user 스코프를 고르면 됩니다.
user 스코프로 설치하면 데스크톱 앱의 Code 탭에서도 동작합니다.
